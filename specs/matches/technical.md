# Мэтчи

Мэтч — строка, а не только пара свайпов. Иначе закрытие, протухание и чат не к чему крепить.

## Данные

`matches`: `id`, `profile_low_id`, `profile_high_id` (меньший id первым, уникальная пара), `status` (`pending`, `active`, `expired`, `unmatched`), `created_at`.

`decide` при первом взаимном положительном жесте вставляет строку `pending`. Повторный взаимный жест ту же строку не дублирует.

Заметка суперлайка остаётся в `swipes.note`. В список она попадает только если зритель — `target_id` того суперлайка.

## Методы

- `GET /api/me/matches` — пары зрителя, где `status` не `unmatched` и не `expired`. Курсор по `id`. В элементе карточка другого человека, `status`, `note` или `null`.
- `DELETE /api/me/matches/:id` — статус `unmatched`. Чужая пара — `404`. Повтор по уже закрытой паре — `204`, состояние то же.

Отмена свайпа смотрит в эту таблицу и при `pending` или `active` отвечает `409`.

Чат переводит `pending` в `active` первым сообщением. Это описано в спеке чата, здесь только статус.
